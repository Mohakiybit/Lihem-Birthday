LIHEM BIRTHDAY WEBSITE

OPEN WITHOUT INSTALLING ANYTHING
1. Extract this entire ZIP.
2. Open offline/index.html in your browser.
Keep its images, fonts, CSS, and JavaScript together in the offline folder.
You can share the complete ZIP with someone else. They should extract it first.

EDITABLE PROJECT
The source folder contains a standalone React + Vite project.
Requires Node.js 22.13+ (or a newer supported release) and npm.
Open a terminal in source, then run:
  npm install
  npm run dev
To build for static hosting:
  npm run build
Upload the contents of source/dist to your static web host.

CUSTOMIZE
Letter: source/src/App.tsx, the message string and Heya Lii greeting.
Appearance: source/src/styles.css.
Images and Ditty font: source/public.
The offline copy is prebuilt; editing source does not update it automatically.

INCLUDED

Lihem's spinning photo reveal, ogre/onion confetti, and working candle controls.
All page text uses Ditty. Reduced-motion preferences are respected.
